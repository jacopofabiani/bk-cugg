Rules

Tournament Format
  • Format Single-elimination bracket tournament.
  • Matches Each match is a best-of-3 series. The first player to win 2 games advances.
  • MVP At the end of each tournament, one card is voted as MVP of the tournament.
Points System
Achievement Points
Each game won within a match +1 per game
Reaching the Final (losing finalist) +2
Winning the Final (tournament winner) +5
Points Example
  • Example A deck wins 2-1 in the quarterfinals, 2-0 in the semifinals, and 2-0 in the final: it earns 2 + 2 + 2 = 6 game points, plus 5 for winning = 11 total.
  • Example A deck loses 1-2 in the final: it earns 1 game point plus 2 for reaching the final = 3 total.
  • Note Points accumulate across all tournaments — the standings show the all-time total.
